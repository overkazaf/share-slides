回合还在跑，你就能插话、改任务、换模型

这就是 UI 5,608 行 vs 内核 2,086 行 换来的东西。值不值，看你信不信「盯着结果看」才是逆向的主要动作。

/queue edit 确实存在

  • 完整动作集：list / add / edit <id> <task> / cancel / rm / drop / clear / run —— 能改一条已排队但还没执行的任务
  • /queue run 在回合中只回「排完这轮再继续」，不打断当前回合

四种可视化档位

  • full（图 + trace）· flow（只要图）· trace（只要行）· off；选择落盘到 UI 偏好文件
  • trace 每行带耗时条和参数摘要，是永久 scrollback，不是刷掉的动画

同页的代价：这 5,608 行几乎没测
