52 个命令里，大约 49 个一个 token 都不花

帮助里归为 direct tools 的有 16 条，其中 11 条走 runDirectTool —— 直接调工具函数，完全绕过 agent loop。你只在真想让它「想一下」的时候才付钱。

一张表同时驱动三件事

  • ui/help.go:23-88 那张 54 行的表，同时喂给帮助、Tab 补全和命令面板 —— 加命令只改一处，三处不会漂

reverse_toolkit 是白名单动作，不是命令注入

  • 20 个外部工具族（r2 · rizin · jadx · ghidra · gdb · binwalk · yara · apktool · frida · angr …），动作固定：info / sections / symbols / imports / strings / functions / disasm
  • angr / unicorn / unidbg / burp / mitmproxy 五个只产出模板，从不真的起进程（retool.go:164）

同页的代价：这条路也是审计盲区

  • reverse_toolkit 申请审批时不带 concerns（retool.go:838）—— 全仓只有 3 处会填 Concerns，这里不在其中
  • 实际后果没有传言那么大：burp 与 mitmproxy 只吐模板；真会起进程的是 frida（frida-ls-devices / frida-ps -Uai）—— 它在 --allow-network 关着时照跑
  • 零 token 很爽，但「绕过 loop」也绕过了 loop 上的那道闸
