## 每页的结构

| 段落 | 作用 |
|---|---|
| **一句话主旨** | 这页要让听众记住的唯一一件事 |
| **怎么讲** | 口语化讲稿，可以照着念；带 `[停]` `[慢]` `[指…]` 之类的舞台提示 |
| **别漏了说** | 最容易讲漏、但漏了这页就白讲的点 |
| **可能被问** | 预判提问 + 怎么答；答不上来的直接写"会后补" |
| **过渡到下一页** | 一句话，把话头交出去 |
