CH 3 · 原理 · L5 · 第二场对撞

Loop 派 vs Graph 派：争的不是数据结构，是「可停可续的最小单位」

上一页把树和图当成两种互补能力。这一页说实话：它们背后是两套对立的工程假设。引爆点只有一句 —— 「这一轮结束了」，谁说了算。
我的立场 → 有便宜的 verifier 就用循环；verifier 只能是人或合规，就用图。
因为图的真正作用不是让 agent 更聪明，是让人能在正确的位置插进去。最强的反驳我自己先说：verifier 的有无不是任务的固有属性，而是工程投入的函数 —— 官方建议原文就是 "encode verification as skills"。我的回应是：造不出 verifier 的那一类，卡的不是「对不对」，是「准不准」。
