CH 4 · 场景

四格里只有一格该交给 agent，另外三格别硬来

看的不是"这活难不难"，是：步骤说不说得清、做完了机器能不能判对错。

真上手前先问三句

  • ① 错了要紧吗？能沙箱、能撤回
  • ② 干完了谁说了算？有不用人看的信号吗
  • ③ 步骤说得清吗？说得清 → workflow，说不清 → agent
  • 三个都行 → 放手干；②不行 → 直接别做

四条硬红线

  • 撤不回来、又不好验：删生产数据、发布、转账
  • 出了事得有人担责的那种判断
  • 只有人能评、还评得慢：品味、关系、政治
  • 喂进去的东西不可信、又没隔开 —— 提示注入真会发生，CH7 有实例

一条挺好使的观察

  • coding 先跑通不是因为程序员多，是编译器和测试本来就是现成的判卷人 —— 反过来说，你这行能造出判卷人，agent 才进得来
