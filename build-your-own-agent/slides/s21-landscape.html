另一个切法：交互面

  • 终端优先 — 心智模型是"结对"：人在场，随时打断Claude Code · Codex CLI · pi · opencode · Aider

2026 年最重要的架构趋势

  • agent 与前端正在解耦：编辑器侧出现了通用协议，仓库侧出现了统一的 agent 调度台
  • 换句话说，"用哪个 agent"和"在哪用"正在变成两个独立选择 —— 这正是自己造 harness 变得可行的前提
