Loop Engineering：最容易被低估的是"转圈"

教科书是 while(true){ llm(); tools(); }；难的全在中断、插队、判停、截断、并发、错误恢复。

判停：四种收敛条件

  • 模型不再要工具（最常见）
  • 最大轮数上限
  • 工具返回 terminate 信号批次内全部 terminate 才停
  • 用户中断 / 出错

三个坑

  • 没有超时：交给工具自管，bash 的 timeout 默认不设
  • 并行写同一文件：真实路径串行化，否则丢更新
  • 报错就是养料：带字段路径回喂，远胜"执行失败"

可借鉴

  • UI 按完成顺序更新、历史按源顺序写，可重放
  • 能力层不抛异常，返回 Result<T,E>
