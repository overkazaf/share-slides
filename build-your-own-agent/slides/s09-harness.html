CH 3 · 原理 · L2–L6

Harness：包在模型外面的那台机器

模型权重之外、让模型干活的全部工程。pi 真有个类就叫 AgentHarness。

快照：冻结配置

  • 冻结 messages / tools / model / systemPrompt；中途改设置下一轮生效

Hook：10 个能改流程的切点

  • 注入消息 / 覆写 system prompt / 改写上下文 / 拦截工具，最狠的是接管压缩

持久化时序

  • 消息结束即落盘，每轮 flush 发存档点；扩展忙时的写排队等它，可重放

相位状态机挡并发

  • idle · turn · compaction · branch_summary · retry
  • 不在 idle 就抛 busy，不是布尔标志位
可借鉴 → 内核做成无状态纯函数；存盘、压缩、权限、回溯全靠外层编排 + 钩子挂上去。分界线画在哪，是造 agent 第一道题。
