关于这次分享

这不是产品宣讲，是一份工程读书笔记加一手代码取证

我在造一个 agent，造之前把这两年的公开工程实践啃了一遍。

为什么讲这个

  • agent 的内容要么概念科普，要么产品广告，中间那层"怎么工程化"很少有人讲
  • 而这层是唯一你能掌控的 —— 模型造不了，界面别人做了，中间只能自己写
  • 断言尽量挂出处：官方博客、arXiv、源码行号。二手转述里见过的数字，一律不上页

你能带走什么

按投入产出排
  • 一套共同词汇 —— harness / context engineering / loop / graph / SKILL
  • 一张决策表 —— 何时写 workflow、何时才轮到 agent、何时别用
  • 一份选型依据 —— "能不能改"为什么比"多好用"值钱
  • 几个能抄的工程模式 —— 会话树、渐进式披露、fork tier 成本模型、生成评判分离
