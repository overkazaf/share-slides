CH 3 · 原理 · L3

工具集是接口设计，不是功能清单

同一个问题 ——"到底该给模型多少工具" —— pi 和 oh-my-pi 给出了两个方向完全相反、但各自都自洽的答案。

少而正交

  • 两个功能重叠的工具 = 每次调用都要让模型做一次无谓的选择，还多一次选错的机会

描述即接口

  • 模型能看到的只有名字、描述、参数 schema。照给新同事写 API 文档的标准写

错误要能自愈

  • 报错必须带上"下一步怎么办"。pi 的参数校验失败会生成带字段路径的多行错误回喂模型

结果必须裁剪

  • 工具结果是最会爆窗口的一块：分页、截断、大结果落盘只回路径
