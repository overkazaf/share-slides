CH 3 · 原理 · L3

工具集是接口设计，不是功能清单

pi 与 oh-my-pi 对"该给模型多少工具"给出了两个相反、却各自自洽的答案。

少而正交

  • 功能重叠 = 每次调用多一次无谓的选择

描述即接口

  • 模型只看到名字、描述、schema —— 照 API 文档写

错误要能自愈

  • 报错要带"下一步怎么办" —— pi 回喂带字段路径的错误

结果必须裁剪

  • 最会爆窗口：分页、截断、大结果只回路径
证据 · pi core/tools/index.ts（7 个）· agent-session.ts（默认 4 个）· oh-my-pi src/tools/index.ts（6 个 essential + BM25）
