SKILL：把说明书挂在墙上，而不是背在身上

"教会 agent 一件事"的最省钱形态。核心机制叫渐进式披露（progressive disclosure）：常驻的只有目录，正文用到才翻开。

代码证据：它有多干净

  • pi 的 Skill 结构体里压根没有 content 字段 —— 正文从未被读进内存，更不可能进 system prompt
  • 注入 prompt 的只有三个字段：name / description / location
  • 而且只有 read 工具在场时才注入 skills 段 —— 没有 read 就没法翻开，那列出来纯属浪费

写好一个 SKILL 的三条

  • description 是唯一的入口：它决定模型会不会翻开你这一页，比正文更值得打磨
  • 正文写流程和判据，不写背景介绍 —— 模型不需要被科普
  • 能做成脚本的别做成文字

顺带一提

  • "渐进式披露"本是人机交互领域的老概念：界面先给最常用的，高级选项藏起来
  • 换到 agent 上，被节省的从"用户的注意力"变成了"模型的注意力"—— 是同一个问题
