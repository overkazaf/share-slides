SKILL：把说明书挂在墙上，而不是背在身上

渐进式披露：常驻的只有目录，正文用到才翻开。

代码证据

  • Skill 结构体没有 content 字段 —— 正文从未进内存
  • 只有 read 在场才注入 skills 段 —— 翻不开就不列

写好一个 SKILL

  • description 是唯一入口：比正文更值得打磨
  • 正文写流程和判据，不写背景科普
  • 能做成脚本的别做成文字

顺带一提

  • "渐进式披露"本是人机交互老概念：省的从用户注意力变成模型注意力
