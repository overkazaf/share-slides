CH 3 · 原理 · L6

六种扩展点，各管一段 —— 选错了会很痛苦

六种做法不是同义词：挂的位置、触发者、代价都不同。
机制你交付的是谁触发什么时候用它代价 / 陷阱
Context fileAGENTS.md / CLAUDE.md 一段文字常驻 永远成立的项目约定 每轮复付 token；写太长稀释注意力
SKILL 一个文件夹（正文 + 脚本）模型判断 特定任务的操作手册 description 写不好就不会被翻开
Slash command 一段提示模板只有人 你高频重复的那几句话 模型不会主动用，是人的快捷键
Tool / MCP 一个可调用接口模型判断 模型要真的"做"一件事 定义常驻烧 token；工具一多越易选错
Hook 一段确定性代码代码强制 必须发生的事：校验、审批、审计 唯一能"强制"，也因此写错卡死主流程
Subagent 一份独立上下文模型派生 大量探索，主线只要结论 token 放大明显；并行写文件等于灾难
一条决策线 → ①「必须发生，还是模型可判断？」必须发生 → Hook；模型判断 → SKILL / Tool。②「知识，还是动作？」知识 → SKILL；动作 → Tool。剩下两个：人的快捷键、上下文的隔离舱。
