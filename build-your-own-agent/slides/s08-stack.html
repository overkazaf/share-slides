把 Agent 拆开：七层，你要写的是中间五层

决定"好不好用"的，是中间的 harness 五层。
两个方向的证据 → ① 16 模型 × 180 修 bug 任务，只换编辑工具格式：Grok Code Fast 1 6.7% → 68.3%，平均 +15pp —— 但越弱的模型收益越大。 ② Terminal-Bench 榜 22 个模型换 harness：中位数 5.39 分，7 个 ≥10 分，最大 20.90 分。
结论：模型是主项，harness 是次项（约 1/4 量级）。但主项买不到差异化，次项才是你能攥住的部分。
