再看用法：为什么我这样搭

每条都有数字撑着，纯凭感觉的我会明说。

Claude Code

主力
  • 闭环最完整：能跑、能看见、能改回来

Codex

派活
  • 自带沙箱和 git：套路清楚的活派出去，回来收 PR

Gemini Notebook

消化
  • 只照你给的材料答，方便核对它没编

Grok

探风向
  • 接 X 实时流：看真实用户在骂什么
任务类型首选量化依据
深度重构 / 跑测试Claude Code + Opus 5 必须真跑测试
日常八成的活Claude Code + Sonnet 5 便宜 2.5 倍
同时跑一堆 / 批量 PRCodex 云端 + Terra $2/$12，价格正合适
批量粗筛 / 过日志GPT-5.6 Luna 比旗舰便宜 25 倍
几个仓库一起翻子代理分头找 不互相带偏，费 token
啃长文档还要给出处Gemini Notebook 凭经验
私有化 / 数据不出境开放权重自建 长活差 12–21 分

有句话得说清楚

  • 同一个 Opus 4.6，最好的 harness 76.4%，Claude Code 58.0%
  • 我选它不是因为分高，是因为能改的地方最多

怎么挑，一句话

  • 按"你人在不在旁边"分：人守着 → 终端；人走开 → 丢云上；人在读材料 → 检索型
  • 默认便宜档，卡住再升

但这么切来切去，本身就很累

  • 四个工具、七种任务，每天在脑子里路由一次 —— 这份心智负担没人给你算钱
  • 所以回到那个定义：下一步由谁决定。挑 ROI 最高的那段写死成自己的 agent —— 每天都干、干得最烦、错了一眼能看出来
