pi 的卖点，是一张"就是不做"的清单

别人 README 写"我支持什么"；pi 的 Philosophy 一条条写"这个我不做，你自己这么弄"。

它自带的工具，就这几个

少到能背下来
  • 定义 7 个，默认只给 4 个：read · bash · edit · write别家动辄挂三四十个 —— 它赌的是"给少了反而不挑错"
    规模：110,436 行 TS · MIT · 81,545 ★ / 10,068 fork（下一页的基准）
  • 没有搜索工具、没有 todo、没有 plan —— 要搜就 grep，要记事就写文件
  • 有用户直接让 pi 给自己生成一套 permissioned_* 工具，把默认四件套关掉 —— 这就是"留空位"

"自己长功能"是真能转起来

  • 扩展文档头一句就是"让 pi 自己写"，写完热加载 —— 功能自己长出来

看得懂、改得动、是你的

  • 聊天记录是人能直接读的 JSONL 树，能 fork / resume 回到任意一步

不只是小圈子自嗨

  • OpenClaw 的底层就是 pi（官方口径："Pi is the minimal agent within OpenClaw"）
pi.dev 首页那句 slogan，也是今天的题眼 → "There are many agent harnesses but this one is yours"
大家喜欢它不是因为功能多，是它特意留了空位给你填。
