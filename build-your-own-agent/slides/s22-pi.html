pi 的卖点，是一份"刻意不做"的清单

别人的 README 写"我们支持什么"。pi 的 README 有一节 Philosophy，逐条写"我们不做什么，以及你该怎么自己做"。

"自扩展"是个真闭环

  • 扩展文档随 npm 包一起发布，system prompt 里直接写死"你自己的文档在哪"
  • 每份扩展文档的第一行就是"让 pi 自己写"
  • 写完热加载，agent 还能自己触发重载 —— "想要个功能就让它自己长出来"真的成立

可读、可改、可拥有

  • 会话是人能读的 JSONL 树：fork / resume / 回到任意一步换条路
  • MIT、依赖极少、版本锁死、配置上拒绝当天新发布的依赖
  • 作者还把自己的真实工作会话公开成了数据集

不只是小圈子自嗨

  • OpenClaw 的底层就是 pi（官方口径："Pi is the minimal agent within OpenClaw"）
  • OpenAI 的开源社区文档里直接点名 pi，与 Codex / OpenCode / Cline 并列
pi.dev 首页的 slogan，也是本场的题眼 → "There are many agent harnesses but this one is yours"
极客喜欢它，不是因为它功能多，而是因为它留了足够的空位给你自己填，并且它相信你填得比它好。
