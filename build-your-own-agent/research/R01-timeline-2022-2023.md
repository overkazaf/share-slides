**一句话贡献**：把「推理轨迹（Thought）」和「外部动作（Action）→ 观测（Observation）」交织进同一个自回归解码循环里，让 LLM 边想边做、用工具反馈纠正幻觉——这是后来几乎所有 agent 框架的默认执行范式（Thought/Action/Observation loop）。

## 2. 「工具 + 推理」奠基论文（MRKL / Toolformer / Self-Ask / CoT）

### 2.1 Chain-of-Thought Prompting Elicits Reasoning in Large Language Models

- **arXiv v1：2022-01-28**（arXiv:2201.11903）。版本历史：v1 2022-01-28 / v2 2022-04-06 / v3 2022-06-01 / v4 2022-06-13 / v5 2022-10-10 / v6 2023-01-10。
  - https://arxiv.org/abs/2201.11903
- **正式发表：NeurIPS 2022**（Advances in Neural Information Processing Systems 35, Main Conference Track）。
  - https://proceedings.neurips.cc/paper_files/paper/2022/hash/9d5609613524ecf4f15af0f7b31abca4-Abstract-Conference.html
- **作者**：Jason Wei（第一作者）、Xuezhi Wang、Dale Schuurmans、Maarten Bosma、Brian Ichter、Fei Xia、Ed H. Chi、Quoc V. Le、Denny Zhou。
- **机构**：全部为 **Google Research, Brain Team**（论文首页唯一署名机构；通讯作者 jasonwei@google.com / dennyzhou@google.com）。
  - https://ar5iv.labs.arxiv.org/html/2201.11903
- **一句话贡献**：只要在少样本示例里写出中间推理步骤，就能在不改模型权重的前提下解锁大模型的多步推理能力——把「推理」变成一种可提示（promptable）的能力，是 ReAct 的直接前提。

### 2.2 MRKL Systems（AI21 Labs）

- **arXiv v1：2022-05-01**，**只有 v1 一个版本**，未见会议发表记录（Semantic Scholar 记录的 venue 为 arXiv.org）。
  - https://arxiv.org/abs/2205.00445
- **全名 / 读音**（论文原文）："the Modular Reasoning, Knowledge and Language (**MRKL, pronounced "miracle"**) system"。
  - https://ar5iv.labs.arxiv.org/html/2205.00445
- **作者**：Ehud Karpas（第一作者）、Omri Abend、Yonatan Belinkov、Barak Lenz、Opher Lieber、Nir Ratner、**Yoav Shoham**、Hofit Bata、Yoav Levine、Kevin Leyton-Brown、Dor Muhlgay、Noam Rozen、Erez Schwartz、Gal Shachaf、Shai Shalev-Shwartz、**Amnon Shashua**、Moshe Tenenholtz（共 17 人）。
- **机构**：**全部为 AI21 Labs**（Yoav Shoham、Amnon Shashua、Ori Goshen 是 AI21 Labs 的联合创始人；本文作者含前两位）。
- **一句话贡献**：最早明确提出「LLM 只负责路由与语言，把计算/检索/知识库交给离散的外部专家模块」的神经-符号模块化架构，是「router + tools」这一 agent 骨架的学术起点。

### 2.3 Self-Ask（Measuring and Narrowing the Compositionality Gap in Language Models）

- **arXiv v1：2022-10-07**（比 ReAct 晚 1 天）。版本：v1 2022-10-07 / v2 2023-05-23 / v3 2023-10-17。
- **arXiv comments 原文**："To appear at **Findings of EMNLP 2023**"。
  - https://arxiv.org/abs/2210.03350
- **作者与机构**（论文首页）：
  - **Ofir Press**（第一作者）— University of Washington, Paul G. Allen School；同时标注 MosaicML
  - Muru Zhang — University of Washington
  - Sewon Min — University of Washington + Meta AI Research
  - Ludwig Schmidt — University of Washington + Allen Institute for AI
  - Noah A. Smith — University of Washington + Allen Institute for AI
  - Mike Lewis — Meta AI Research
  - https://ar5iv.labs.arxiv.org/html/2210.03350
- **一句话贡献**：提出「组合性缺口（compositionality gap）」这一度量，并用 Self-Ask 提示让模型显式地自问自答子问题、可插入搜索引擎回答——是「显式分解 + 外部检索」这条线的代表作。

### 2.4 Toolformer（Meta AI）

- **arXiv v1：2023-02-09**，**只有 v1**。
  - https://arxiv.org/abs/2302.04761
- **正式发表：NeurIPS 2023**。
  - https://papers.nips.cc/paper_files/paper/2023/hash/d842425e4bf79ba039352da0f658a906-Abstract-Conference.html
- **作者**：Timo Schick（第一作者）、Jane Dwivedi-Yu、Roberto Dessì、Roberta Raileanu、Maria Lomeli、Luke Zettlemoyer、Nicola Cancedda、Thomas Scialom。
  - ⚠️ 差异提示：**NeurIPS 正式版的作者列表比 arXiv v1 多一位 Eric Hambro**（dblp 记录的 NeurIPS 2023 版本为 9 人，arXiv v1 为 8 人）。引用时注意版本。
- **机构**：**Meta AI Research（FAIR）**；Roberto Dessì 另有 **Universitat Pompeu Fabra** 归属（论文首页 † 标记）。
  - https://ar5iv.labs.arxiv.org/html/2302.04761
- **一句话贡献**：用自监督方式让模型自己标注「该在哪里插入 API 调用」，从而把工具使用**烧进模型权重**而不是靠提示词——与 ReAct 的「提示词编排」是两条互补路线，也是后来 function calling 微调的思想源头。

## 7. 这一阶段解决了什么、留下了什么（为下一阶段铺垫）

### 7.1 解决了什么（2022-01 → 2023-12）

1. **确立了 agent 的基本执行范式**：ReAct 的 Thought → Action → Observation 循环成为事实标准（arXiv 2022-10-06 / ICLR 2023）。
2. **确立了工具调用的两条技术路线并最终收敛**：
   - 提示词编排路线（MRKL 2022-05 → ReAct 2022-10 → LangChain 2022-10）；
   - 权重内化路线（Toolformer 2023-02）；
   - 最终由 **OpenAI Function Calling（2023-06-13）** 把 schema 化的工具调用变成 API 一等公民，结束了"靠正则解析模型输出"的时代。
3. **确立了 agent 的三件套抽象**：Planning / Memory / Tool use（Lilian Weng, 2023-06-23），并被 Reflexion（语言化反思）、Generative Agents（memory stream + reflection + planning）分别做出了可复用的实现。
4. **完成了从概念到基础设施的落地**：LangChain（2022-10）→ AutoGPT/BabyAGI（2023-03/04）→ HuggingGPT（2023-03）→ AutoGen（2023-08）→ CrewAI（2023-10），一年之内 agent 从"论文里的一个 prompt 技巧"变成了有框架、有包管理、有社区的工程门类。GitHub Octoverse 2023（2023-11-08）记录到生成式 AI 项目数量**同比增长 248%**，langchain 与 Auto-GPT 均被点名为首次贡献者激增的项目。
   - https://github.blog/news-insights/research/the-state-of-open-source-and-ai/
5. **完成了叙事启蒙**：Generative Agents 的"25 个 agent 的小镇"和 AutoGPT 的 20 天 10 万 star，让"agent"成为主流词汇。

### 7.2 留下了什么（正是下一阶段要解决的）

| 遗留问题 | 2023 年的证据 |
|---|---|
| **长程可靠性 ≈ 0** | GAIA（2023-11-21）：人类 92% / GPT-4+插件 **15%**。AgentBench（2023-08-07）系统性地展示了开源模型与闭源模型在 agent 任务上的巨大差距。 |
| **没有终止与自我校验机制** | AutoGPT 死循环成为通用吐槽点（Tom's Hardware / NYT / Fast Company）。Reflexion 提出的"语言化反思"是第一次系统性的解法，但仍依赖有明确成败信号的任务。 |
| **记忆是外挂而非能力** | 全靠向量库 + 上下文拼接（BabyAGI 用 Chroma/Weaviate；Generative Agents 手工设计三维打分检索）。上下文窗口在 2023 年才刚从 4K→16K（06-13）→128K（11-06）。 |
| **成本与延迟不可控** | 每一步一次 LLM 调用；无缓存、无并发、无预算约束的工程范式。 |
| **缺少标准化的工具接入协议** | 每个框架自定义 tool schema；ChatGPT Plugins 的 manifest 与 OpenAI function schema 各行其是，跨生态不可移植。（→ 这正是 2024 年 MCP 一类协议出现的动因） |
| **缺少人机协同的中间态** | 2023 年的默认设定是"全自主"，而实践反复证明需要 human-in-the-loop（Clara Shih via TechCrunch；Tom's Hardware 的"没机会介入"批评）。 |
| **缺少评测** | 2023 年上半年几乎没有 agent benchmark，全靠 Twitter demo；AgentBench（08）和 GAIA（11）出现在这一年的尾巴上，标志着行业开始要求"拿数据说话"。 |

**一句话总结这一阶段**：2022—2023 年解决的是「**agent 能不能跑起来**」，没解决的是「**agent 能不能跑对、跑完、跑得起**」。
