## 全局叙事线

```
为什么值得逐行读（基线 + 两套编排层）
  → 循环：真实控制流比 while(true) 多出什么
  → 会话：为什么是树，落盘长什么样
  → 上下文：prompt 怎么拼、满了怎么办、SKILL 怎么省 token
  → 工具：为什么只有四个，edit 到底怎么匹配
  → 外壳：扩展面 / 模型接入层 / 自绘 TUI
  → 抄走：12 条可迁移清单 → 第 (3) 讲 oh-my-pi 实现原理
```

一句话主张（贯穿全场）：

> **一个 agent 的难点不在「让模型调工具」，在「工具调完之后的所有事」。**
> 这一讲就是把「所有事」这三个字，摊成源码。
