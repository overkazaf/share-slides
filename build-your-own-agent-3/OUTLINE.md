## 全局叙事线

```
上一篇讲了「怎么造」→ 这一篇讲「造到极致长什么样」
体量与血统 → 内核 → 上下文 → 模型层 → Rust 热路径 → 规则与记忆 → 工程文化
                                                          ↓
                                        能抄的五条 / 别抄的六条
```

一句话主张（贯穿全场）：

> **omp 的价值不在它做了什么，而在它把每个决定的代价都摊开给你看了。**
> 抄功能会死；抄它「怎么判断该不该做」才活。

与前两篇的关系：
- 第一篇给了地图（harness 七层），omp 是这张地图上唯一一个把七层全点满的样本
- 第二篇讲 pi 的极简（4 个工具就能做 agent），本篇讲另一个极端 —— 同一份代码基座，6.45 倍的体量
- **两篇必须成对看**：pi 证明下限，omp 证明上限，中间那段才是你要待的地方
